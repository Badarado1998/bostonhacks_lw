# Claude-specific notes
- `AGENTS.md` above is the shared rulebook. Follow it exactly; this file only adds Claude-specific tips.

- Keep your own task list, but **issues are the source of truth** for status.
- When context gets long, re-read `AGENTS.md`, `docs/TASKS.md` and your open issues instead of relying on memory.
